# Projeto 1 — Programação Web (UEPB · 2026.2)

**Aluno(a):** André Vinícius Barros Macambira
**Disciplina:** Programação Web · Prof. Rodrigo Alves Costa

## Sobre

Aplicação fullstack (API Express em camadas + SQLite + frontend Bootstrap com Vanilla JS).
**Domínio:** controle de uma concessionária de veículos, com concessionárias, veículos e usuários. A modelagem está em [MODELAGEM.md](MODELAGEM.md).

## Estrutura

- `s1/` — exercícios da Semana 1: os quatro pilares da POO em JavaScript.
- `MODELAGEM.md` — modelagem de classes do Projeto 1 (Semana 2).
- `backend/` — API do Projeto 1 em camadas (concessionárias e veículos), com CORS liberado para o `frontend/`.
- `frontend/` — SPA em Vanilla JS e Bootstrap que consome o `backend/` (Semana 4). Estados e casos de teste em [frontend/TELAS.md](frontend/TELAS.md).
- `s3/banco-api` e `s4/banco-frontend` — exercício guiado da Semana 4 (clientes e contas), usado como modelo para o `frontend/`.
